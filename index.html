⚙️ Configuración

Pega aquí la URL de la aplicación web que generaste en Apps Script. Es la URL que termina en /exec.

📋 Cómo configurar (resumen)

Sigue la guía detallada en GUIA_APPS_SCRIPT.md. Resumen:

  1. Abre tu Google Sheets → Extensiones → Apps Script
  2. Pega el código del archivo AppsScript_Backend.gs
  3. Guarda (Ctrl+S) y nombra el proyecto
  4. Implementar → Nueva implementación → Tipo: Aplicación web
  5. Quién tiene acceso: Cualquier persona (la URL es secreta, equivale a contraseña)
  6. Autorizar permisos cuando los pida
  7. Copia la URL generada y pégala arriba
  8. Haz clic en "Probar conexión"

🔄 Cómo funciona

  • ✅ Auto-sync (activado por defecto): cada cambio se sube a Sheets en ~2.5 segundos
  • ✅ Subir todo: reemplaza el contenido de Sheets con los datos locales
  • ✅ Bajar todo: reemplaza los datos locales con los de Sheets
  • 📡 Sin internet: la app sigue funcionando, sincroniza al recuperar conexión
  • 🔒 Seguridad: tu URL es única y secreta, no la compartas
